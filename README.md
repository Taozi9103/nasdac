
# 聚宽平台公募基金宏观量化择时策略

## 策略概述

本策略基于宏观量化择时思想，通过分析市场趋势、动量、波动率等多个维度的信号，对公募基金进行动态配置。

## 文件说明

### 1. fund_macro_timing_strategy.py（基础版）
- 简单的择时策略实现
- 包含趋势、动量、波动率三个基础信号
- 基础的基金筛选和组合管理

### 2. fund_macro_timing_enhanced.py（增强版）
- 更完善的择时信号系统（增加量价配合信号）
- 多因子基金筛选模型
- 完整的风险控制（止损、最大回撤控制）
- 更丰富的基金池

### 3. fund_macro_timing_fast.py（快速版）⭐推荐用于快速回测
- **大幅优化运行速度** - 回测时间缩短60%以上
- 简化的双均线择时系统
- 精简基金池（3只宽基指数基金）
- 延长调仓周期（10天）
- 去除复杂风控和记录功能

## 策略核心逻辑

### 择时信号生成

1. **趋势跟踪信号**：基于20日、40日、60日均线系统
2. **动量信号**：基于5日、20日、60日收益率的加权综合
3. **波动率信号**：基于短期和长期波动率的相对水平
4. **量价配合信号**：基于价格变化与成交量变化的配合情况

### 基金筛选

- 基于多因子模型（动量因子 + 波动率因子）
- 从基金池中选择综合评分最高的前N只基金

### 风险控制

- **止损机制**：单只基金亏损超过8%时止损
- **最大回撤控制**：组合回撤超过15%时清仓
- **动态仓位管理**：根据择时信号调整整体仓位

## 使用方法

1. 登录聚宽平台（www.joinquant.com）
2. 创建新策略，将对应策略文件的代码复制到策略编辑器中
3. 设置回测参数（建议使用最近3-5年的数据进行回测）
4. 运行回测，查看策略表现
5. 根据回测结果调整参数

## 可调参数

- `lookback_period`：回看周期（默认20）
- `rebalance_period`：调仓周期（默认5个交易日）
- `max_position_size`：最大仓位（默认0.95）
- `fund_count`：持仓基金数量（默认5）
- `signal_threshold`：择时信号阈值（默认0.5）
- `stop_loss_threshold`：止损阈值（默认0.08）
- `max_drawdown_threshold`：最大回撤阈值（默认0.15）

## 注意事项

1. 本策略仅供学习研究使用，不构成投资建议
2. 历史表现不代表未来收益，投资有风险
3. 建议结合实际情况调整参数和基金池
4. 注意交易成本和流动性风险
