
## 1. Product Overview
这是一个量化投资小助手应用的登录/注册页面复刻项目，主要包含登录、注册、忘记密码和用户手册功能，目标用户是对量化投资感兴趣的学习者和研究者。
- 为用户提供简洁美观的用户界面，支持用户登录、注册和密码重置功能，并提供详细的使用说明文档。

## 2. Core Features

### 2.1 User Roles
| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| Normal User | Email registration | 使用登录、注册、重置密码、查看使用说明 |

### 2.2 Feature Module
1. **登录页面**: 用户名/邮箱登录，密码输入，登录按钮，忘记密码链接
2. **注册页面**: 用户名、密码、邮箱、验证码输入，获取验证码按钮，验证并注册按钮
3. **忘记密码页面**: 邮箱、验证码、新密码输入，获取验证码按钮，重置密码按钮
4. **使用说明页面**: 用户手册内容展示

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 登录页面 | 登录模块 | 用户可以使用用户名/邮箱和密码登录 |
| 注册页面 | 注册模块 | 用户可以设置用户名、密码、邮箱进行注册 |
| 忘记密码页面 | 密码重置模块 | 用户可以通过邮箱重置密码 |
| 使用说明页面 | 用户手册 | 展示应用的功能说明 |

## 3. Core Process
用户访问网站 → 选择登录/注册/忘记密码/使用说明 → 输入相关信息 → 完成操作 → 进入应用/查看手册

## 4. User Interface Design
### 4.1 Design Style
- Primary color: 蓝色为主色调，辅以浅蓝和白色
- Button style: 圆角矩形，蓝色填充按钮，白色文字
- Font: 现代无衬线字体
- Layout style: 卡片式布局，居中对齐
- Icon/emoji style: 简洁的线条图标

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 登录页面 | 登录模块 | 蓝色主题色，卡片式布局，输入框，蓝色按钮，简洁风格 |
| 注册页面 | 注册模块 | 同样的蓝色主题，输入框，蓝色按钮，验证码功能 |
| 忘记密码页面 | 密码重置模块 | 一致的设计风格，密码重置表单 |
| 使用说明页面 | 用户手册 | 文档式布局，清晰的标题和段落 |

### 4.3 Responsiveness
- Desktop-first, 响应式设计，支持移动设备适配
